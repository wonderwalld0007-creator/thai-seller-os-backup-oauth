Privacy Policy

PERSONAL USE · ENCRYPTED BACKUP

A personal cloud backup utility.

Thai Seller OS Backup is operated locally by its account owner to protect selected local files with encrypted backups stored in the owner's Google Drive. It is not a public backup service and does not offer accounts to website visitors.

How it is used

  1. The owner chooses the local files and the backup destination.
  2. Backup content is encrypted locally using restic before an approved upload.
  3. rclone provides Google Drive access through Google's official OAuth authorization flow.
  4. Restores are checked locally. Unattended scheduling is a separate setup step and is not activated by this website.

Google Drive access

The requested permissions are read-only access to existing Drive files and file-level access to files created by, or explicitly made available to, this application. Read-only permission covers the account's Drive files; operations are configured to use the selected backup location. That configuration is not a Google-enforced folder-only permission.

Write permission is used only for separately approved backup operations. Existing backup content is not made public by authorizing the application.

This informational website does not sign you in, request Drive access, accept uploads, or contain backup data, OAuth credentials, or a recovery password.

Read the Privacy Policy for data access, storage, retention, and how to revoke authorization.
